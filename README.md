# transitvisuals
**Webpage** for viewing  railroadmmap from **travic.app** in 5 different styles .  Decorative  Styles for a **screensaver** via [WebView2 Web Page Screensaver for Windows](https://github.com/muro-dot/webview2-webpage-screensaver-for-windows) or **wallpaper** via [lovely wallpaper](livelywallpaper.app). 

Find it here: 
[transitvisuals](https://clicktricks.github.io/transitvisuals/?ui=true)

Pressing H turns the UI on and off
