# transitvisuals
Transitvisuals is a **Webpage** for viewing  railroadmaps from **travic.app** in 5 different styles .  Decorative  Styles for creating **screensavers** via [WebView2 Web Page Screensaver for Windows](https://github.com/muro-dot/webview2-webpage-screensaver-for-windows) or **wallpapers** via [lively wallpaper](livelywallpaper.app). 

Find the page here: 
[transitvisuals](https://clicktricks.github.io/transitvisuals/?ui=true)

Pressing **H** turns the UI on and off.

Select **number 1 to 5** at the top on the left for a different look.

The **Name of a place** can be typed in on the left.

**Navigating on the map** is possible after **clicking on stop** which stops **Panning** as well as **Zoom**
