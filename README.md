# transitvisuals
**Webpage** for viewing  railroadmmap from **travic.app** in 5 different styles .  Decorative  Styles for a **screensaver** via [web-page-screensaver](https://github.com/janemiceli/web-page-screensaver-windows) or **wallpaper** via [lovely wallpaper](livelywallpaper.app). 

Find it here: 
https://clicktricks.github.io/transitvisuals/?ui=false

Pressing H turns the UI on and off
